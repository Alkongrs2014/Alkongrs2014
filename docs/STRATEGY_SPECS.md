# مواصفات المحرّك — المرجع الذي بُني منه المحرّك المستقلّ

هذه المواصفة مستخرجةٌ من تاريخ المشروع (CLAUDE.md) ومن الشيفرة، وهي
المصدر الذي كُتب منه `tests/reference/` **بلا استيرادٍ من الإنتاج**. وحيث
خالفت الشيفرةُ المواصفةَ وُسم ذلك **تعارضاً** وحُسم بالدليل.

> الحدّ الصادق: لأن المواصفة استُخرجت من الشيفرة جزئياً، فالمرجع يكشف
> زلّات التنفيذ (إشارة، إزاحة بمقدار واحد، معالجة `null`، اعتماد على
> الترتيب، فريمٍ خاطئ، حالة قديمة) ولا يكشف مواصفةً خاطئةً في ذاتها. ولهذا
> وُجدت الحالات الذهبية المحسوبة يدوياً: هي Oracle للمرجع نفسه.

## §1 الرياضيات القياسية (كلُّها قبل اكتمال النافذة `null`)

| المؤشّر | التعريف |
|---|---|
| SMA(p) | متوسّطٌ بسيط لآخر p |
| EMA(p) | بذرةٌ = SMA لأوّل p، ثم `α·x + (1−α)·prev` و`α = 2/(p+1)` |
| RSI(14) | Wilder: فروق، بذرةُ متوسّطَي الربح والخسارة لأوّل p، ثم `(قديم·(p−1)+جديد)/p`؛ `l = 0 ⇒ 100` |
| MACD(12,26,9) | الخطّ = EMA12 − EMA26؛ الإشارة = EMA9 **على قيم الخطّ غير الفارغة**؛ المدرّج = الخطّ − الإشارة |
| بولنجر(20,2) | الوسط SMA20، والانحراف **للمجتمع** (÷p) |
| ATR(14) | TR الأولى = h−l ثم `max(h−l, |h−c₋₁|, |l−c₋₁|)`؛ بذرة متوسّط أوّل p ثم Wilder |
| ADX(14) | TR و±DM من الشمعة الثانية؛ `+DM = up` إن `up > dn` و`up > 0`؛ البذرة **مجموع** p ثم `S − S/p + جديد`؛ DX = `100·|P−M|/(P+M)`؛ ADX بذرتُه متوسّط أوّل p قيمة DX ثم Wilder؛ يحتاج `n ≥ 2p+1` |
| الستوكاستك(14,3) | `%K = (c−LL)/(HH−LL)·100` (مدىً صفريّ ⇒ null)؛ `%D` متوسّط 3 **كاملة** من %K |
| MFI(14) | التدفّق = tp·v؛ موجبٌ إن tp صعد، سالبٌ إن نزل، ويُهمل التساوي؛ بلا سالب: 100 إن وُجد موجب وإلا null |
| OBV | تراكمٌ بإشارة تغيّر الإغلاق × الحجم |
| عرض بولنجر | `(up−lo)/mid` إن `mid > 0` |
| الانضغاط | رتبة آخر عرض في آخر 120: `#(أصغر)/(n−1)·100`، ودون 20 قيمة null |
| التباعد (RSI) | قممٌ/قيعان محلّية بـk=3 (التساوي مسموح)، آخر اثنتين بفاصل ≥ 5 ضمن آخر 60؛ تجاوزُ السعر > 0.5·ATR عند الثانية؛ هابطٌ: قمّة أعلى وRSI أدنى؛ صاعدٌ: قاع أدنى وRSI أعلى؛ الأحدث أوّلاً |
| VWAP الجلسة | داخل `[start,end]` وبحجمٍ موجب؛ `Σtp·v/Σv`؛ الانحراف مرجَّحٌ بالحجم؛ < شمعتين أو بلا حجم ⇒ null |
| نطاق الافتتاح | الشمعات في `[start, start+min)`؛ مكتملٌ حين توجد شمعة ≥ نهاية النافذة |
| وسيط الحجم | على آخر 20 **قبل** الأخيرة، الموجبة وحدها، ودون 5 ⇒ null |
| التجميع | مفتاح `⌊t / (وسيط الفروق × العامل)⌋` — زمنيٌّ لا بالفهرس |

## §2 الشمعة المغلقة

- الفريمات اللحظية: جاريةٌ إن `t + طولها > الساعة`. اليومي: جاريةٌ إن يومُها UTC ≥ يوم الساعة.
- الختم ليس دقيقةً كاملة ⇒ طبعةٌ جزئية تُحذف.
- يُحذف من الذيل كلُّ ما سبق حتى أوّل مغلقة (وتبقى شمعةٌ واحدة على الأقل)، ثم يُحلَّل **آخر 259**.
- **ساعة الشمعة** = نهاية آخر شمعة ‎15د‎ مغلقة + 1ms — للأسهم في `fetch-market` و`track-strategies` معاً. والسلسلة الممتدة (`anx`) تُحلَّل بساعة الحائط عمداً: شمعاتُ ما قبل الافتتاح تقع بعد آخر شمعةٍ رسمية.

## §3 النتيجة الفنية لكل فريم

سبع بوابات، **المنطقة الميتة** `tol = 0.15·ATR` (`|فرق| ≤ tol ⇒ 0`)، والغائبة لا تدخل المقام:

|---|---|---|
| 1 | px مقابل e200 | 2.5 |
| 2 | e50 مقابل e200 | 1.5 |
| 3 | px مقابل e20 | 1.0 |
| 4 | hist مقابل 0 (إن وُجد hist) | 1.5 |
| 5 | hist مقابل histPrev، أو الراية `histRising` إن غابت القيمة (إن وُجد hist) | 0.5 |
| 6 | RSI: `> 55 ⇒ +1`، `< 45 ⇒ −1`، وإلا 0 | 1.0 |
| 7 | px مقابل bbMid | 0.5 |

`score = clamp(±100, Σ(v·w)/Σw·100)`، والمقام صفر ⇒ 0.
- الكلية: متوسّطٌ موزون `15m:0.5 · 1h:1 · 4h:1.5 · 1d:2` على الفريمات الموجودة، ولا فريم ⇒ null.
- النطاقات: حدود `[-45,-15,15,45]`، والحدّ للأعلى؛ الهيستريسس ‎3‎ نقاط خطوةً خطوة.

## §4 سياق التأكيد (CONFIRMED)

- يُقصّ كلُّ فريم بساعة التأكيد (§2) ثم يُعاد التحليل.
- السعر الأساس إغلاقُ أدقّ فريمٍ مغلق (15m ← 1h ← 4h ← 1d؛ والممتدة أوّلاً في PRE/AFTER).
- لكل استراتيجية سعرُها إغلاقُ **فريمها** المغلق، وتُعاد المستويات به.
- فريمٌ غائب ليس تعذّراً؛ سلسلةٌ موجودة بلا إغلاق ⇒ `off`.
- الكريبتو: الجلسة يوم UTC كامل.
- المستويات (`levelsFrom`) والتقويم (`sessionOf`) **مدخلاتٌ** للمرجع لا جزءٌ منه.

## §5 الاستراتيجيات العشر

- **النتيجة** = `round((Σw·v/Σw + 1)/2·100)` على البوابات غير الغائبة. `active ⇔ sc ≥ 55`.
- **النطاق** `[55,70,85]`.
- `tier(x,a,b)`: `x≥a ⇒ +1 · x≥b ⇒ 0 · وإلا −1`، و`tierLo` معكوسه.
- `range(v,lo,hi)`: داخله +1، ضمن ربع العرض خارجه 0، وإلا −1.
- `agree(v,d,flat)`: `|v|≤flat ⇒ 0`.
- `dayTrend` = `agree(an1d.score, d, 15)` وتُسقَط حين يُثبَّت اليوميّ.

## §6 الإجماع والتوافق

**الوزن**:
- `clamp(0.4,1.8, 1 + edge/2)` إن قيست الحافّة، وإلا 1.
- حالة السوق تضرب في `clamp(1 + (edgeRegime − edge)/2)`.
- ثم يُقصّ الناتج مرّةً أخرى.

**الكتلة**: `w·sc/100` للنشطة وحدها.

**التعارض**: أقلّيةٌ فوق 0.35 من المجموع ⇒ `mixed`.

**الثقة**:
- `high` ⇔ اتفاق ≥ 0.78 وعائلتان وثلاث استراتيجيات، وتنزل إلى `med` إن لم تُقَس أيّ استراتيجية.
- `med` ⇔ اتفاق ≥ 0.62 واثنتان.
- واحدةٌ ⇒ `solo`.

**التوافق** (`scsFrom`):
- `net = (up−dn)/total` و`cover = min(1, total/3)`.
- `str = |net|·(0.35 + 0.65·cover)`.
- `scs = sign(net)·str` و`pct = round(100·str)`.
- المتعارض ⇒ `scs = 0` معلَن.

**درجة الفرصة**: `q = clamp01(base + 0.15·scs·sd)`.

## §7 الاتجاه

- `base`: النطاق ≤ 1 ⇒ −1، وإلا +1 (وبلا نطاق: النتيجة < −15 ⇒ −1).
- `uni`: الفريمات الأربعة كلُّها > 15 أو < −15.
- **`resolveOpp`**:
  - أوّلُ شرطٍ مفروض **بترتيب SCANS** لا يعاكس نطاقاً متطرّفاً (0/4) ولا إجماعَ الفريمات يصير الاتجاه، وإلا `base`.
  - وإجماعُ الفريمات يعلو على الكلّ.
  - يُقبل الشرط الذي اتجاهُه (المفروض، أو وسمه، أو اتجاه الرمز) يساوي الاتجاه.
  - لا مقبول ⇒ `dir = null`.
