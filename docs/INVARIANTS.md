# عقد الثوابت — INVARIANTS

هذه الوثيقة **العقد الرسمي** للمشروع. كلُّ ثابتٍ له معرّف (`INV-xx`)
يستشهد به `npm run doctor` والاختبارات وسجلّ الإخفاقات. خرقُ ثابتٍ من
الصنف **CRITICAL** يمنع النشر. **WARNING** لا يمنعه إلا إن مسّ صحّة
البيانات أو الحساب. **INFO** توثيقٌ فقط.

> حركة السوق الطبيعية ليست خرقاً لأيّ ثابت. الثوابت تحكم **صحّة البرنامج**
> لا **نتيجة الصفقة**: توصيةٌ محسوبةٌ صحيحاً ثم خسرت ليست خللاً.

## ٧. الحدود المعلنة (ليست خروقات)

- **توليد البيانات الموثوق يعتمد على الجهاز المحلي** (ياهو يحظر السحابة، وTwelve Data محدود). المراقبة والبوّابات تعمل ‎24/7‎ في السحابة؛ التوليد يتوقّف حين يُطفأ الجهاز — قيدُ بنيةٍ تحتية لا علّة.
- الترتيب مقطعيٌّ عمداً: الرتبة المئوية `q0`/`base` تتغيّر بإضافة رموز، وهذا مقصود (INV-22/23 تستثنيها).
- `resolveOpp` يأخذ أوّلَ شرطٍ مفروض **بترتيب `SCANS`** — الأولويةُ ترتيبُ التعريف، وهي حتمية.
